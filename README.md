# Personal Portfolio Website

A modern, minimal portfolio built with Next.js, React, and Tailwind CSS.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Features

- ✨ Modern, minimal design
- 📱 Fully responsive navigation
- 🎨 Tailwind CSS styling
- ⚡ Next.js 14 App Router
- 🎯 TypeScript for type safety

## Structure

- **Home** - Hero landing page
- **About** - Your story and skills
- **Projects** - Portfolio work with demos
- **Playground** - Interactive content, games, 3D models
- **Resume** - Your CV and experience

## Deployment

Deploy instantly on [Vercel](https://vercel.com):
```bash
vercel
```

## Customize

1. Update `components/Navigation.tsx` - Change "Your Name" to your actual name
2. Fill in page content in `app/*/page.tsx` files
3. Modify colors and styling in `tailwind.config.ts`
